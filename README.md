# Open SDV Platform

An open-source vehicle body-control platform built from scratch.

## Main areas

- `application_core/` — C++ application services
- `real_time_controller/` — real-time C firmware
- `contracts/` — shared commands, events and signal definitions
- `simulation/` — vehicle simulator and automation tools
- `tests/` — unit, integration and acceptance tests
